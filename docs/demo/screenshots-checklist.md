# Investor Demo Screenshots Checklist

Capture these screens for the investor deck or walkthrough:

- Login screen with customer credentials ready.
- Customer dashboard showing KYC, consent, balance, and latest decision.
- KYC status screen showing `VALID` seeded NIN status.
- Consent screen before and after granting consent.
- Loan application form with salary advance product selected.
- Decision screen showing approval and reason codes.
- Offer screen showing principal, total repayment, duration, rate, and accept action.
- Loan account screen after acceptance.
- Repayment schedule screen after loan creation.
- Admin dashboard placeholder.
- Admin credit review screen showing application, decision, loan, and ledger counts.
- Admin audit trail screen showing `demo.*` audit events and mock labels.

Every screenshot that includes mock data should preserve visible sandbox or mock wording.
