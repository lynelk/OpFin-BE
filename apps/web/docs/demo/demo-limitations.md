# Investor Demo Known Limitations

- Affordability and decisioning are deterministic mock rules.
- Consent is demo-scoped to credit processing.
- Mobile money disbursement is sandbox/mock only.
- KYC is read from seeded backend user status.
- No live mobile money, CRB, production KYC, insurance, savings, investment, or employer integrations are connected.
- Admin lists are investor-demo snapshots, not production reporting workflows.
